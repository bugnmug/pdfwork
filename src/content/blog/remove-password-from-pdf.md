**If you know a PDF's password, you can save a copy that opens without it: open the file in a password remover, type the password once, and download the unlocked copy.** With [Remove Password](/remove-password) this takes under a minute on a phone or a computer, and the file never leaves your device.

## Steps

1. Open [Remove Password](/remove-password).
2. Choose the locked PDF, or drop it on the page.
3. Type the password in the box.
4. Press **Unlock PDF** and download the copy. It opens without a password from now on.

Nothing is uploaded. The page loads its PDF engine into your browser and unlocks the file there, which matters when the file is a bank statement, an e-Aadhaar or a salary slip. The meter in the top bar shows how many bytes of your files have been sent anywhere: it stays at 0 B.

## Two kinds of PDF password

| Kind | What it does | Can it be removed? |
| --- | --- | --- |
| Open password (user password) | You must type it to see anything | Only if you know it |
| Permissions password (owner password) | The file opens, but printing, copying or editing is blocked | Yes, without the password |

Indian banks, UIDAI and the income tax department all use open passwords. If you don't know yours, the formats are usually published:

## Why unlock a PDF at all?

- **Portals refuse locked files.** The income tax department asks you not to upload password-protected files ([Income Tax Department](https://www.incometax.gov.in/iec/foportal/scanning-document?mobile-app=1)).
- **Loan apps ask for the password** of your bank statement, or for an unlocked copy ([Moneyview](https://moneyview.in/personal-loan/how-to-upload-bank-statement-in-your-money-view-loan-app)).
- **Other tools need it.** Merging, compressing or converting a locked statement fails until it is unlocked.
- **You open it every week** and are tired of typing the password.

## Another way: print to PDF in Chrome

Chrome can also make an unlocked copy: open the PDF in Chrome, type the password, press print and choose **Save as PDF**. Tax guides describe this for ITR-V acknowledgements ([TaxGuru](https://taxguru.in/income-tax/remove-password-itr-acknowledgement.html)). The catch: printing redraws every page, so links, bookmarks and form fields are lost, and the text can come out less clean. A password remover keeps the file exactly as it was, minus the password.

## Keep the original

Signed documents such as e-Aadhaar and e-PAN carry a digital signature that only the original file passes. Keep the original download next to the unlocked copy, and send the original whenever someone needs to verify the signature.
